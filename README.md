## 🇵🇱 O Projekcie
**CatApp** to mobilna aplikacja stworzona w technologii **Flutter**, dedykowana miłośnikom kotów. Aplikacja łączy się z zewnętrznym API (TheCatAPI), aby dostarczać użytkownikom losowe zdjęcia kotów oraz szczegółowe informacje o różnych rasach.

Projekt jest przykładem implementacji nowoczesnej aplikacji z wykorzystaniem asynchronicznych zapytań sieciowych, mapowania obiektów JSON oraz zarządzania stanem w ekosystemie Flutter.

### Główne Funkcjonalności
* **Losowy Kot:** Pobieranie i wyświetlanie losowego zdjęcia kota.
* **Katalog Ras:** Lista ras kotów z możliwością podglądu szczegółów (opis, temperament, pochodzenie).
* **Interfejs:** Czysty i responsywny UI zgodny z Material Design.
* **Obsługa Błędów:** Eleganckie komunikaty w przypadku braku połączenia z internetem.

### Technologie
* **Framework:** Flutter
* **Język:** Dart

### Uruchomienie Projektu

## 🇺🇸 About the Project
**CatApp** is a mobile application built with **Flutter**, designed for cat enthusiasts. The app connects to an external API (TheCatAPI) to provide users with random cat images and detailed information about various breeds.

This project serves as an example of a modern implementation using asynchronous network requests, JSON serialization, and state management within the Flutter ecosystem.

### ✨ Key Features
* **Random Cat:** Fetching and displaying a random cat image.
* **Breeds Catalog:** A list of cat breeds with details (description, temperament, origin).
* **UI/UX:** Clean and responsive interface following Material Design guidelines.
* **Error Handling:** Graceful error messages when offline or API is unreachable.

### 🛠 Tech Stack
* **Framework:** Flutter
* **Language:** Dart
* **Networking:** `http` / `dio` package

### 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/KarolPiechaczek/CatApp.git](https://github.com/KarolPiechaczek/CatApp.git)
    cd CatApp
    ```
2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```
3.  **Run the app:**
    Connect your device or start an emulator, then run:
